# Inline Installation Review UX — 2026-09-19

- Removed the separate item-level review list from Installation Review.
- Approval/redo controls now live directly inside the existing Work Item Evidence cards.
- Reviewer can select a Work Item, a specific installed proof photo, multiple evidence items, or Select All.
- One inline sticky action bar provides Approve / Redo for the current selection.
- Existing APPROVED / REDO state is visible on the same Work Item/photo card.
- Survey/measurement and approved design stay visible beside installed proof as review context.
- Redo creates granular correction only for selected evidence and routes it to the assigned installer.
- No second job-level confirmation is required: last required approval automatically marks the installation approved; any redo automatically marks the job for redo while preserving granular correction scope.
