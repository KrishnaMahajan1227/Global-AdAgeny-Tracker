# Darshan Ad Agency — Owner Dashboard Demo Release

**Release:** `2026.10.31.3` (source code; requires a fresh frontend build + deployment)

This release starts from **v2026.10.31.2** (the previously shared no-Campaigns project) and retains the original operational dashboard layout, its financial privacy switch, all existing data contracts and production-completion migrations. It does not delete or rewrite any database data.

## Changes requested by the client

- **Removed** separate `Attention required` section. The same next-action queue remains available in **Work Orders by client → Needs action**, including search and direct **Next** button. No redundant action summary appears elsewhere.
- **Removed** `Site pipeline` strip. The top delivery KPIs and per-Work-Order current stages already show operational site progress. Stage chips remain clickable and open scoped shop lists.
- **Removed** redundant `Quick access` strip, since it duplicated the left navigation without saving clicks.
- **Kept the approved dashboard visual style**, 2-column mobile / 4-column desktop KPI cards, familiar Work Orders rows, client delivery and owner-only finance view.
- **Refined top KPIs** into four distinct concepts: Open Work Orders, Active clients, Sites delivered (with completion %), Linked sites pending. Zero-linked-site cases show a dash and proper scope messaging instead of invented counts.
- **Simplified Client delivery** to summary-only rows: client, open/completed/needs-action counts, delivered sites/progress, one direct **Open client orders** link. Removed repeating individual Work Order names in this section.
- **Reduced default Work Orders list** from 10 to 6 before **Show all**. Search, filters, next-stage links and complete-order filters remain.
- **Optimized large client lists**: avoid filtering every Work Order for every client; index once by client and aggregate action counts once. This removes an O(clients × orders) in-memory scan from the dashboard.
- **Preserved all previous Campaign removal work**. Both agency and client sidebars have no Campaigns link, and old Campaign bookmarks redirect to direct Work Orders. Historic `campaign_id`/`project_id` fields and data remain intact.
- **Bumped deploy version** to `Work Orders · v2026.10.31.3` to make an old deployed/cached frontend obvious. `version.json` is generated by the production build.
