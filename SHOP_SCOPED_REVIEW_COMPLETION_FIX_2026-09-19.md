# Shop-scoped review completion fix — 2026-09-19

- Approval/redo applies only to explicitly selected Work Item(s) or installation photo(s) inside the current shop.
- A partial redo no longer moves the whole installation job to the Redo tab or removes the shop from Pending Review.
- The shop remains in Pending Review until every Work Item has the complete evidence chain: Survey/Measurement, Approved Design, Installation Proof.
- Every required Work Item and current installation proof must be individually approved.
- Any open installation correction keeps the shop in Pending Review.
- Approving corrected evidence resolves only its matching open correction.
- Review UI now states shop completion rules and shows a clearer selected-evidence action bar.
